# 稳定性验证测试清单
## 迁移后功能测试

**测试时间**: 请在浏览器中打开游戏完成以下测试  
**预计时间**: 10-15分钟  

---

## 🔴 核心功能测试 (必须全部通过)

### 1. 游戏启动测试
- [ ] 游戏能正常加载，无报错
- [ ] 显示加载画面，然后进入主菜单
- [ ] 控制台(F12)无红色错误

### 2. 道具系统测试 (ITEMS数据)
- [ ] 开始新游戏，选择武器后进入游戏
- [ ] 击杀敌人，拾取掉落的道具
- [ ] 按E打开商店，能看到道具列表
- [ ] 购买道具，道具效果正常生效

### 3. 敌人系统测试 (ENEMY_TYPES数据)
- [ ] 进入房间，敌人正常生成
- [ ] 不同房间有不同类型敌人
- [ ] 敌人会正常移动和攻击
- [ ] 击杀敌人有经验值掉落

### 4. 武器系统测试 (Weapon类)
- [ ] 武器能正常发射/攻击
- [ ] 升级武器，伤害提升
- [ ] 不同武器类型效果正常

### 5. 房间系统测试 (Room类)
- [ ] 清理房间后门正常开启
- [ ] 进入下一房间正常
- [ ] 不同房间类型正常(普通/商店/Boss)

---

## 🟡 高级功能测试

### 6. Boss战测试
- [ ] 找到Boss房间
- [ ] Boss正常生成，有Boss血条
- [ ] Boss技能正常释放
- [ ] 击杀Boss有奖励掉落

### 7. 层间过渡测试
- [ ] 通过楼梯进入下一层
- [ ] 新层敌人强度提升
- [ ] 地图重新生成

### 8. 存档测试
- [ ] 游戏中按ESC，选择"保存并退出"
- [ ] 重新打开游戏，选择"继续游戏"
- [ ] 存档数据正确恢复

---

## 🟢 边缘情况测试

### 9. 长时间运行测试
- [ ] 游戏运行5分钟以上
- [ ] FPS保持稳定
- [ ] 无内存泄漏(浏览器不卡顿)

### 10. 多房间切换测试
- [ ] 连续进入5个以上房间
- [ ] 房间间切换流畅
- [ ] 敌人和道具正常刷新
