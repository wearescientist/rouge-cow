# v0.16.0 武器升级系统重设计

## 概述
参考《吸血鬼幸存者》(Vampire Survivors) 重新设计了武器升级系统，为14种武器各自设计了8级独立升级路线。

## 主要变更

### 🎯 升级路线重设计
- **鞭子**: 双鞭 → 三鞭 + 吸血 + 暴击
- **镰刀**: 双重斩击 → 三重斩击 + 30%即死
- **魔杖**: 双重 → 三重 + 连锁闪电
- **飞刀**: 8连发 → 命中分裂 + 弹跳
- **斧头**: 双斧 → 三斧 + 往返双伤
- **十字架**: 弹跳爆炸 → 无限弹跳 + 神圣新星
- **火球**: 分裂 → 陨石 + 燃烧蔓延
- **手里剑**: 回旋 → 12枚风暴
- **冰锥**: 范围冰冻 → 暴风雪
- **环刃**: 双环 → 三重电锯模式
- **毒镖**: 毒爆 → 瘟疫传播
- **圣经**: 永久环绕
- **闪电**: 雷暴 + 随机落雷
- **圣水**: 庇护所 + 回血回甲
- **大蒜**: 无敌帧效果

### ⚡ 超武升级
- 所有超武比8级基础武器强 **50%-100%**
- 超武不是数值叠加，而是机制质变
- 超武特殊效果在描述中清晰标注

### 🔧 新机制支持
- **延迟攻击**: 镰刀的多重斩击有时间间隔
- **双重/三重攻击**: 同时发射多个投射物
- **弹跳**: 命中后寻找新目标继续攻击
- **分裂**: 命中时产生子投射物
- **连锁**: 闪电等武器可连锁多个敌人
- **即死**: 对低血量敌人直接击杀
- **吸血**: 按比例恢复生命值
- **暴击**: 独立暴击率和暴击伤害
- **返回伤害**: 回旋镖返程也造成伤害
- **燃烧蔓延**: 火焰会传染给附近敌人

## 文件变更
