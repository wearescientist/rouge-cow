# 🎵 音效生成完整方案

**全自动 ElevenLabs 音效生成 + 可视化选择器**

---

## 📋 使用流程（3步）

### 第1步：获取API密钥

1. 访问 https://elevenlabs.io/
2. 注册/登录账号
3. 进入 **Profile > API Keys**
4. 点击 **Create API Key**
5. 复制生成的密钥（格式: `sk_xxxxxxxx...`）

### 第2步：配置密钥

**方法A：使用.env文件（推荐）**
```bash
# 复制模板文件
copy .env.example .env

# 用记事本编辑 .env 文件，填入你的API密钥
ELEVENLABS_API_KEY=sk_你的密钥
```

**方法B：环境变量**
```bash
set ELEVENLABS_API_KEY=sk_你的密钥
```

### 第3步：运行生成脚本

```bash
node scripts/generate-audio-elevenlabs.js
```

**输出：**
- `generated_audio/` 目录下生成所有音效（4个变体 × 26个音效 = 104个文件）
- `generated-audio-selector.html` 选择器网页

## 🎮 使用选择器

### 打开选择器
双击 `generated-audio-selector.html` 用浏览器打开

### 界面功能
```
⚔️ 武器攻击
├─ 鞭子攻击  [▶变体1] [▶变体2] [▶变体3] [▶变体4]
├─ 镰刀挥砍  [▶变体1] [▶变体2] [▶变体3] [▶变体4]
└─ ...

💥 命中音效
├─ 命中肉体  [▶变体1] [▶变体2] [▶变体3] [▶变体4]
└─ ...

[▶ 试听所有选择] [💾 导出选中音效]
```

### 操作步骤
1. **点击播放按钮** 听每个变体
2. **选择最佳变体**（点击单选按钮）
3. **重复** 直到所有音效都选好
4. 点击 **"💾 导出选中音效"**
5. 下载 `selected-sounds.json`

## ⚙️ 技术说明

### API限制
- **免费版**: 每月10,000字符额度
- **生成26个音效 × 4变体 = 约需 5,000字符**
- 绰绰有余！

### 文件格式
- **输出**: MP3
- **采样率**: 自动优化
- **时长**: 按Prompt指定（0.05s - 1.0s）

### 生成时间
- **预估**: 5-10分钟（含API延迟）
- **网速**: 每个音频约10-20KB

## 🛠️ 故障排除

### 问题1：API密钥错误
```
❌ 错误: 未找到 ElevenLabs API 密钥
```
**解决**: 确认 `.env` 文件存在且格式正确

### 问题2：API限制
```
错误 429: Too Many Requests
```
**解决**: 脚本已内置500ms延迟，如仍报错请等待1分钟后重试

### 问题3：生成失败
```
错误 500: Internal Server Error
```
**解决**: ElevenLabs服务器问题，稍后重试
