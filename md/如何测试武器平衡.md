# 🤖 AI武器平衡测试 - 使用指南

**全自动测试，无需启动游戏，无需手动操作！**

---

## 🚀 快速开始（3种方式）

### 方式1：双击运行（最简单）
1. 双击文件 `测试武器平衡.bat`
2. 等待10-30秒
3. 查看报告

### 方式2：命令行运行
```bash
# 进入游戏目录
cd E:\AI\game\rougelike-cow

# 运行测试
node scripts/auto-balance-test.js
```

### 方式3：NPM运行
```bash
npm run test:balance
```

## 🔧 系统要求

- **Node.js** 14.0+ （没有？去 https://nodejs.org/ 下载LTS版）
- **无需浏览器**
- **无需启动游戏**

---

## ⚙️ 高级配置

编辑 `scripts/auto-balance-test.js` 修改测试参数：

```javascript
this.testConfig = {
    simulationRuns: 100,   // 模拟次数（越多越准但越慢）
    testDuration: 60,      // 战斗时长（秒）
    enemyDensity: 50,      // 敌人数量
    roomSize: { w: 800, h: 600 }
};
```

## 🎯 平衡标准

| 等级 | DPS比例 | 说明 |
|:---|:---:|:---|
| S | >150% | 过强，需要削弱 |
| A | 120-150% | 偏强，可以微调 |
| B | 80-120% | ✅ 平衡正常 |
| C | 50-80% | 偏弱，可以加强 |
| D | <50% | 过弱，需要大幅加强 |
