# Changelog - 2026-03-08

## 今日已完成（可确认）

### 1) 无缝开场第一轮定稿
- 新增 `src/ui/SeamlessPrologueController.js`，承接“开始新游戏 -> 开场动画 -> 武器选择”流程。
- 第一幕不再单独播放 `start1.png`，而是直接复用主菜单背景，保证进入开场时更自然。
- 后续分镜使用 `assets/sprites/story/start2.png`、`start3.png`、`start4.png`。

### 2) 开场演出节奏重做
- 分镜停留时间整体放慢，不再按“快速播图”的方式推进。
- 图片之间新增黑场淡入淡出过渡，提升故事感和章节感。
- 开场文案支持点击/按键推进，也支持跳过。

### 3) 对白与字幕表现重做
- 对白切换为当前版本：
  - 第一幕：`终于到家了。。。` / `这。。。发生了什么。。。`
  - 第二幕：`爸！妈！你们在哪！` / `其他人都去哪了！`
  - 第三幕：`“别来找我们，活下去。”` / `你们知道的。。。从小我就不听话。。。`
  - 第四幕：`师傅。。。我可以做到吗？` / `爸爸妈妈！你们等着，我来救你们了！`
- 原先悬浮气泡改为底部字幕卡，避免各张图构图差异导致的定位错位。
- 字幕改为更慢的逐字机效果，标点停顿更长。

### 4) 开场音频时机修正
- 为逐字对白补上像素风说话音，并修复 `AudioContext` 解锁时机。
- 点击“开始新游戏”时立即播放 `menu` BGM，让开场动画全程有音乐托底。

### 5) 版本同步
- 仓库版本标记更新为 `v0.33 (Seamless Prologue Update)`。
- 主菜单可见版本号更新为 `v0.33`。
- 页面标题更新为 `牛牛的结合 - v0.33 无缝开场迭代`。
