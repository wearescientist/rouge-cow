## v0.17.4 - 2026-03-01
### 重大Bug修复：玩家不死 + Boss不掉落

**问题1：玩家负血不死**
- 原因1: `player.takeDamage()` 没有返回值，导致死亡检测失败
- 原因2: 允许HP负数（`< -999`），导致状态不一致
- 原因3: Boss技能伤害（冲撞/震荡波）没有检查死亡状态
- 修复: 
  - 添加返回值 `return this.hp <= 0`
  - HP限制在0（不允许负数）
  - Boss技能添加死亡检测和无敌检查

**问题2：Boss死亡不掉落**
- 原因: `applyDamage()` 只检查 `e.tier === 3`，但Boss是 `tier 4` 和 `isBoss`
- 修复: 改为 `e.isBoss || e.tier >= 3`
- 现在Boss死亡正确掉落：武器选择箱 + 金色宝箱 + 楼梯

## v0.10.4 - 2026-02-23
### 重大Bug修复 - T2精英敌人不动

**问题根源：**
T2精英敌人（兔子、鸟）有特殊技能`jump`和`dive`，但代码结构有缺陷：

```javascript
if (special === 'jump' && 条件A) {
    if (距离条件) { 设置速度; }
    // 如果距离不满足，vx/vy不被设置！
} else if (special === 'dive' && 条件A) {
    if (距离条件) { 设置速度; }
    // 同样问题
} else {
    // 普通追踪 - 但进不来！
}
```

**影响：**
- 兔子（jump）：玩家距离>200时，vx/vy不被设置，敌人卡住
- 鸟（dive）：玩家距离<100或>400时，vx/vy不被设置，敌人卡住

**修复方案：**
使用`normalChase`标志，当特殊技能距离条件不满足时，继续执行普通追踪逻輪。
