## 技术规格汇总

| 项目 | 规格 |
|-----|------|
| **分辨率** | 1920x1080 |
| **帧率** | 30fps |
| **总时长** | 约33秒 |
| **风格** | 16-bit像素风 |
| **色调** | 前段暖色（橙紫）-> 后段冷色（蓝紫黑）|
| **底部留白** | 200px 黑色（用于裁剪AI水印）|

## 给豆包的整体要求

在每个提示词前加上：
```
Create a pixel art animation scene for a roguelike game intro. 
Style: 16-bit retro gaming aesthetic, dark fantasy with slight cosmic horror elements.
Resolution: 1920x1080. Bottom 200px should be pure black for text overlay.
```

**使用方法**: 把每个分镜的提示词分别给豆包生成，然后用剪辑软件（剪映/PR）拼接起来即可！
