# 🚀 编辑器启动说明（简化版）

## 已简化！

移除了 Node.js 后端，现在只需要 **Vite 开发服务器**即可运行。

## 启动方式

### 一键启动（推荐）

双击运行：
```
打开编辑器.bat
```

### 手动启动

```bash
cd tools/editor
npm install    # 首次运行
npm run dev    # 启动
```

然后浏览器访问： http://localhost:5173

## 数据保存

1. 在编辑器中修改数据
2. 点击"保存"按钮
3. 浏览器下载文件
4. 将文件复制到项目对应目录

## 变更记录

- ✅ 移除后端服务器（server 目录已删除）
- ✅ 移除不必要的依赖（axios/express/cors 等）
- ✅ 改为直接读取本地文件
- ✅ 保存改为导出下载方式
- ✅ 简化启动流程

## 依赖列表

**前端**: Vue 3, Element Plus, Pinia, Vue Router  
**构建**: Vite, Sass
