## 1. 简化版敌人体系 (4-Tier)

### 核心原则
- **只做基础属性**: HP、速度、伤害、颜色
- **简化特殊能力**: 射手能发射子弹，其他只有基础属性差异
- **不做复杂DOT**: 中毒等持续伤害效果已移除

### 1.1 等级划分

```
┌─────┬───────────┬──────────┬─────────────────────────────────────────┐
│ Tier│ 名称      │ 颜色     │ 属性基准                                │
├─────┼───────────┼──────────┼─────────────────────────────────────────┤
│ T1  │ 普通怪    │ 白色 #fff│ HP 10-25, 速度 50-180, 伤害 1           │
│ T2  │ 精英怪    │ 四色     │ HP 12-60, 速度 60-300, 伤害 1-3         │
│ T3  │ 小Boss    │ 金色 #fa0│ HP 60-100, 速度 40-160, 伤害 3-4        │
│ T4  │ 区域Boss  │ 深红渐变 │ HP 5000-17500(逐层递增), 伤害 5         │
└─────┴───────────┴──────────┴─────────────────────────────────────────┘
```


## 2. 掉落系统 (简化)

### 2.1 敌人击杀掉落

| 等级 | 道具掉落 | 武器掉落 |
|:-----|:---------|:---------|
| T1白 | 1% | - |
| T2彩 | 5% | 2% |
| T3金 | 100%×1 | 50% |

### 2.2 房间清理奖励

- **Boss房**: 道具升级奖励 (50%×1, 35%×3, 15%×5)
- **普通房**: 5%概率掉落血包 (+1红心)

### 2.3 武器箱 (简化)

- 掉落在地，E键开启
- 3选1界面 (暂停游戏)
- 选项: 已有武器升级 / 新武器

## 3. 技术实现要点

### 3.1 敌人选择器 (简化版)

```javascript
// T2替换T1的概率: 层数×10%，最高60%
const t2ReplaceRate = Math.min(floor * 0.1, 0.6);
```

### 3.2 射手型敌人射击

```javascript
// 简单直线子弹，无复杂效果
if (this.type === 'ranged' && this.specialCd <= 0) {
    game.bullets.push({
        x: this.x, y: this.y,
        vx: Math.cos(angle) * speed,
        vy: Math.sin(angle) * speed,
        dmg: this.dmg,
        isEnemyBullet: true
    });
}
```

### 3.3 玩家状态

```javascript
// 简化版：只有基础属性和hitTimer
```
