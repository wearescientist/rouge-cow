# DESIGN_Room_Material_System_v0.34

## 一、目标

本轮不是推翻六层主题，而是在保留现有世界观顺序的前提下，把 `地板 / 墙 / 转角 / 门` 升级成同一套有厚度、有空间感的房间材质系统。

核心原则：

- 六层主题 DNA 保持不变
- 一层必须回归“白色菌丝”压暗后的灰白体系
- 地板、墙、转角、门必须一起设计，不能再各自为战
- 重点先解决“平、薄、像占位图”的问题，而不是继续靠滤镜掩盖

## 二、现状判断

当前正式资产的问题不是主题错误，而是完成度不一致：

- 地板主题性最强，基本能看出六层叙事顺序
- 墙体有楼层配色，但受光面 / 背光面 / 厚度关系不够明确
- 转角是当前最大短板，和地板、墙体的材质语言脱节
- 门的识别性有了，但更像图标，不像真正的空间开口

结论：

- 六层主题可继续沿用
- 需要升级的是“材质完成度”和“空间构件逻辑”
- `corner_walls/layer*_v10_seamless_corner.png` 可作为转角升级方向参考

## 四、统一升级规则

### 4.1 地板

- 保留每层已有主题图案
- 提高明暗层次，避免整片均匀发灰
- 中景纹理可读，边缘纹理更克制
- 一层地板应偏灰白，不再带明显绿调

### 4.2 墙体

- 必须能读出厚度和结构面
- 顶面、侧面、背光面要有稳定分工
- 不同楼层主要通过材质和染色区分，而不是只换一层滤色

### 4.3 转角

- 转角必须成为空间锚点，而不是单纯补洞
- 需要和墙体共享同一结构逻辑
- 优先参考 `v10 seamless corner` 的无缝体积感

### 4.4 门

- 门应表现为“空间阈值”，不是 UI 图标
- 门框材质必须跟墙体属于同一体系
- 开合状态需要保留，但形态要更像真正通道

## 五、第一层纠偏说明

第一层当前正式地板在后处理压暗后，容易被误读成灰绿。该方向不成立。

第一层正确目标：

- 原始意象：白色菌丝 / 苍白孢子 / 冷灰洞穴
- 压暗后观感：灰白、骨白、灰褐，不应主导成绿色
- 开场动画和封面若继续使用第一层语汇，也必须遵守同一配色基因

禁止方向：

- 灰绿色苔藓感
- 脏绿沼泽感
- 温暖米黄神圣感

1. 先确认六层提案方向无误
2. 选定一层做成正式资产样板间
3. 再统一推进 `地板 / 墙 / 转角 / 门`
4. 最后把材质升级接回正式渲染链
