## 创新机制说明

### 时间操控机制
```javascript
// 怀表 - 常驻子弹时间
timeScale: 0.8  // 游戏时间流速

// 时光机 - 死亡回溯
deathRewind: {
    enabled: true,
    seconds: 10,
    uses: 3
}

// 预知水晶 - 显示敌人未来位置
showGhost: true
ghostDelay: 3  // 秒
```

### 空间扭曲机制
```javascript
// 相位靴 - 穿墙冲刺
phaseDash: {
    enabled: true,
    duration: 0.5,  // 冲刺期间
    throughWalls: true
}

// 虫洞 - 双向传送
wormhole: {
    portalA: null,  // 可放置位置
    portalB: null,
    duration: 30
}
```

### 因果律机制
```javascript
// 薛定谔的猫
schrodinger: {
    alive: true,
    dead: false,
    onDeath: () => Math.random() < 0.5 ? revive() : die()
}

// 概率云
probabilityCloud: {
    hitChance: 0.7  // 只有70%概率被命中
}
```

### 进化机制
```javascript
// 进化因子
evolution: {
    interval: 300,  // 5分钟
    stats: ['atk', 'speed', 'def'],
    bonus: 0.2
}
```
