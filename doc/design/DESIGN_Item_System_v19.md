## 二、道具协同系统 (Synergy)

### 核心机制
当玩家同时持有特定组合的道具时，触发超越单个道具效果的**协同效果**。

| fire_hell | 燃烧地狱 | 火焰附魔 + 火焰之石 | 火焰伤害+10，燃烧扩散 |
| tesla_coil | 特斯拉线圈 | 雷电宝珠 + 电池 | 周围持续雷电伤害 |

### 代码实现

```javascript
class SynergyManager {
    checkSynergies() {
        const owned = Object.keys(this.itemManager.owned).map(Number);
        for (const rule of SYNERGY_RULES) {
            if (rule.items.every(id => owned.includes(id))) {
                this.activeSynergies.set(rule.id, rule);
            }
        }
    }
    
    applySynergies(stats) {
        for (const synergy of this.activeSynergies.values()) {
            synergy.effect(stats);
        }
    }
}
```

## 四、新效果实现

### 4.1 以撒经典效果

```javascript
// 豆浆 - 高攻速低伤害
if (s.soyMilk) {
    s.fireRate *= 4.0;
    s.projSize *= 0.5;
}

// 犹大的影子 - 玻璃大炮
if (s.judas) {
    s.fireRate *= 2.0;
    s.maxHp = Math.min(s.maxHp, 2);
}

// 失落的灵魂 - 飞行但无法回血
if (s.lost) {
    s.fly = true;
    // 在受伤处理中禁用红心回复
}

// 硫磺火 - 持续激光
if (s.brimstone) {
    // 在武器系统中处理为持续伤害激光
}

// 妈妈的刀 - 蓄力飞刀
if (s.chargeKnife) {
    // 按住蓄力，伤害随时间增加
    // 飞刀可回收，回收时回蓝
}
```

## 五、平衡性设计

### 5.1 属性递减机制
防止单一属性堆叠过高：
```
第1个: 100%效果
第2个: 70%效果
第3个: 50%效果
第4个+: 30%效果
```

### 5.2 诅咒道具风险收益
- **犹大的影子**: 伤害×2，但容错率极低
- **豆浆**: 特效流核心，但直接伤害极低
- **血之契约**: 伤害×3，但持续掉血需配合吸血

### 5.3 神话道具限制
- 每局游戏只能获得1-2个
- 只能通过特定方式获得（隐藏房间、Boss掉落、特殊事件）

## 六、后续扩展方向

1. **更多协同组合**: 计划扩展到30种协同
2. **道具合成**: 3个白→1个绿，3个绿→1个蓝等
3. **道具献祭**: 献祭道具换取临时强力buff
4. **道具诅咒**: 某些道具会叠加负面效果
5. **道具进化**: 特定道具+特定条件=进化版
