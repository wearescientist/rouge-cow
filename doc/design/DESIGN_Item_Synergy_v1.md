# DESIGN_Item_Synergy_v1

## 设计目标

- 让被动叠加后产生可见、可感知、可复述的变化
- 联动优先改行为，不做纯隐藏增伤
- 先做二件联动，少量保留三件终极联动位

## 设计原则

- 联动必须有视觉反馈
- 联动优先绑定标签和行为，不把逻辑全部写死在单武器上
- 联动增强主胜场，不主动抹掉武器原有弱点

## 第一批落地联动

### 1. 聚焦折射

- 条件：`focus_lens + clover`
- 适用：`laser / wand / knife`
- 效果：
  - 连续命中同一敌人时逐步聚焦增伤
  - 暴击时触发小范围幸运新星
- 视觉：
  - 目标身上出现聚焦层数
  - 暴击时额外炸出小型金色爆闪

### 2. 炼成反应

- 条件：`alchemist_flask + spinach`
- 适用：`fireball / poison_dart / holy_water / radiance`
- 效果：
  - 火、毒、区域残留命中时有概率触发炼成爆裂
  - 爆裂附带额外毒灼残留
- 视觉：
  - 橙绿混色爆裂
  - 残留区颜色更浓、边缘更亮

### 3. 血甲反震

- 条件：`pummarola + armor`
- 适用：全局，偏向近战和贴身构筑
- 效果：
  - 玩家真实受伤时在周围触发一次反震脉冲
  - 反震造成范围伤害并附带少量回血
- 视觉：
  - 红白双色脉冲环
  - 玩家脚下瞬时爆出护体冲击波

### 4. 王权拾取势能

- 条件：`crown + attractorb`
- 适用：全局
- 效果：
  - 拾取经验球或金币后获得短时势能层数
  - 势能提高少量伤害、射速、移速
- 视觉：
  - 玩家周围出现短时金色回旋粒子
  - 高频拾取时形成王冠光环

### 5. 疾风导流

- 条件：`wings + focus_lens`
- 适用：`lightning / laser`
- 效果：
  - 玩家移动时，闪电获得额外链距和额外一次连锁
  - 玩家移动时，激光获得额外束宽和更强转向导流
- 视觉：
  - 闪电更容易拉出长链
  - 激光束体更厚，转向更灵动

### 6. 滞留领域

- 条件：`spellbinder + alchemist_flask`
- 适用：`holy_water / bible / radiance`
- 效果：
  - 区域、圣环、领域获得额外持续、范围或 tick 密度
  - 区域消失后留下缩小版残留场
- 视觉：
  - 圣池退去后残留一圈更淡的余场
  - 压场型 build 更有“越站越满”的氛围

## 终极联动预留

- `focus_lens + clover + laser`：神罚折光
- `spinach + alchemist_flask + fireball`：焚城炼狱
- `pummarola + armor + whip`：血誓圣裁

## 技术落地

- 第一阶段不新建复杂注册中心，先基于 `PassiveManager.getStats()` 产出联动状态
- 由战斗结算口消费联动字段，验证玩法价值
- 联动稳定后再抽出 `SynergyRegistry` 做标签化治理
