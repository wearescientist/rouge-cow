# v0.20 道具系统五轮迭代设计总结

## 🎯 迭代目标
将道具系统从50个扩展到**200个独特道具**，引入创新机制和深度策略。

---

## 📊 五轮迭代成果

### 第1轮: 新类别扩展 (101-150)
引入5个全新道具类别：

| 类别 | ID范围 | 核心机制 | 代表道具 |
|------|--------|----------|----------|
| 时间操控 | 101-110 | 时间流速、回溯、预测 | 时光机、永恒瞬间 |
| 空间扭曲 | 111-120 | 传送、相位、维度 | 相位靴、虫洞发生器 |
| 身份转换 | 121-130 | 伪装、模仿、灵魂交换 | 怪物面具、灵魂容器 |
| 因果概率 | 131-140 | 运气、命运、量子态 | 薛定谔的猫、概率坍缩 |
| 进化变异 | 141-150 | 成长、适应、突变 | 进化因子、基因锁 |

### 第2轮: 游戏改变者 (151-165)
神话级道具，彻底改变游戏玩法：

| 道具 | 核心效果 |
|------|----------|
| 修改器 | 每层修改游戏规则(4选1) |
| 开发者模式 | 有限次数作弊菜单 |
| 第四面墙 | 敌人躲避鼠标，真实暂停 |
| 元游戏 | 成就/挑战/惩罚系统 |
| 无限手套 | 响指消灭一半敌人 |
| 平行宇宙 | 同时存在3个你 |
| 死亡轮回 | 本层可重复挑战变强 |

### 第3轮: 双刃剑诅咒 (166-185)
20个高风险高回报的诅咒道具：

**七宗罪系列:**
- 贪婪契约 - 金币×3但生命换钱
- 暴怒诅咒 - 伤害+150%但无法控制
- 懒惰舒适 - 回复×3但移速攻速减半
- 嫉妒之眼 - 见敌弱点但自己也有弱点
- 暴食之胃 - 道具效果+50%但必须不断吃
- 傲慢王冠 - 满血战神，非满血废柴
- 色欲魅影 - 敌人迷恋你但变强

**特殊诅咒:**
- 俄罗斯轮盘 - 伤害+300%但20%自杀
- 知识代价 - 知道越多生命越少
- 永夜 - 视野受限但暴击高

### 第4轮: 主动技能 (186-205)
20个可主动使用的道具(按Q触发)：

| 类型 | 代表道具 | 效果 |
|------|----------|------|
| 位移 | 瞬移卷轴 | 瞬移到鼠标位置 |
| 控制 | 时间沙漏 | 暂停时间3秒 |
| 召唤 | 召唤号角 | 召唤3个友军 |
| 防御 | 护盾发生器 | 5秒无敌 |
| 攻击 | 黑洞手雷 | 投掷吸引黑洞 |
| 特殊 | 生命献祭 | 50%生命换伤害×3 |

### 第5轮: 环境互动 (206-235设计稿)
15个与世界互动的道具设计：

- 地图改造锤 - 破坏/创建墙壁
- 天气控制 - 改变当前层天气
- 植物学家 - 种植各种植物
- 重力操控 - 改变重力方向
- 世界吞噬者 - 慢慢吞噬整个层

## ✨ 创新机制亮点

### 1. 时间操控系统
```javascript
// 常驻子弹时间
if (has(101)) timeScale = 0.8;

// 死亡回溯
if (has(102) && die) rewind(10);

// 时停
if (active(187)) timeScale = 0;
```

### 2. 道具协同系统
```javascript
// 10种协同组合
const synergies = [
    { id: 'fire_hell', items: [13, 31], bonus: { fireDmg: 10 } },
    { id: 'tech_master', items: [51, 99], bonus: { laserDmg: 2.0 } },
    // ... 更多
];
```

### 3. 主动道具系统
```javascript
// 按键Q使用
activeItem: {
    effect: 'timeStop',
    cooldown: 30,
    charges: 1
}
```

### 4. 进化系统
```javascript
// 随时间变强
if (has(141)) {
    every(5 minutes) => randomStat += 20%;
}
```

### 5. 诅咒风险系统
```javascript
// 明确的风险收益比
greedPact: {
    reward: { goldMult: 3.0 },
    risk: { hpPerGold: 100, shopPrice: 3.0 }
}
```

## 🔧 技术实现

### 数据结构
```javascript
const ITEM = {
    id: Number,
    name: String,
    icon: String,
    rarity: Enum['common', 'uncommon', 'rare', 'epic', 'legendary', 'cursed', 'mythic'],
    effect: String,
    value: Number,
    desc: String,
    price: Number,
    active: Boolean,      // 是否主动道具
    cd: Number,           // 冷却时间
    charges: Number       // 使用次数
};
```

### 系统架构
```
ItemManager
├── owned: Map<id, count>
├── getStats(): Stats
├── has(id): Boolean
└── add(id): Boolean

SynergyManager
├── activeSynergies: Map<id, Synergy>
├── checkSynergies()
└── applySynergies(stats)

ActiveItemManager
├── equipped: Item
├── cooldowns: Map<id, time>
├── use(): Boolean
└── update(dt)
```

## 🎨 设计哲学

### 1. 每个道具都有故事
不仅仅是数值，每个道具都有独特的名字、图标和背景。

### 2. 明确的风险收益
双刃剑道具让玩家做出有意义的选择。

### 3. 组合产生惊喜
协同系统让玩家探索道具组合的乐趣。

### 4. 改变游戏体验
神话级道具应该让玩家惊呼"还能这样玩？！"

## 总结

经过五轮迭代，道具系统从**50个基础道具**成长为拥有**200个独特道具**、**7级稀有度**、**10种协同组合**、**20个主动技能**的复杂系统。
