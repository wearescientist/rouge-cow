# DESIGN_Item_Expansion_v1

## 目标

- 扩大道具体系的可玩空间，不再只靠基础面板加成
- 让道具分为“稳态成长”“行为改写”“构筑联动”“风险回报”四种不同体验
- 优先复用现有武器、被动、联动系统，避免新系统过重

## 外部参考提炼

- 《以撒》的强点在“行为改写型道具”很多，同一武器会因为道具组合彻底变样
- 《吸血鬼幸存者》的强点在“被动既能进化，又能做稳定成长底座”
- 适合本项目的方向不是照搬房间制主动道具，而是做：
  - 少量强改写道具
  - 一批稳定泛用被动
  - 一批联动触发器
  - 一批风险换收益道具

## 道具分类方案

### 1. 核心面板类

- 作用：提供稳定成长，但不再承担全部乐趣
- 例子：
  - `赤红火药`：伤害提升，火系联动增强
  - `冷钢护符`：暴击率和暴伤小幅提升
  - `迅捷导轨`：投射速度、转向稳定性提升
  - `大口径膛线`：投射物体积、贯穿体积略增

### 2. 行为改写类

- 作用：直接改攻击方式
- 例子：
  - `反射晶片`：投射物第一次命中后分裂反射
  - `月相透镜`：激光/投射会在边缘折返一次
  - `血色回旋芯`：近战和飞刀类附带回旋二段
  - `重力井`：区域武器会将敌人往中心缓慢拉拽
  - `诡雷火种`：火球、毒镖、圣水会在死亡点留下陷阱区

### 3. 联动触发器

- 作用：自己不强，但能点燃 build
- 例子：
  - `审判印记`：暴击时触发小型圣裁
  - `炼成催化剂`：火/毒/圣水发生元素反应时扩大效果
  - `镜像骰面`：分裂、复制、折射类效果再触发一次弱化副本
  - `余烬圣歌`：持续伤害命中达到阈值时产生神圣新星
  - `导雷骨针`：链雷命中同一目标后会额外分叉回周围

### 4. 风险回报类

- 作用：主动制造爽点，而不是纯上行
- 例子：
  - `裂心之冠`：满血增伤，残血减伤或减速
  - `诅咒香炉`：敌人数量、速度提高，但幸运和掉率提升
  - `过载针剂`：攻速暴增，持续时间缩短
  - `血契烙印`：持续掉血，吸血和处决变强
  - `空洞圣杯`：最大生命降低，超武效果增强

### 5. 资源滚雪球类

- 作用：给经济类被动真正的战斗价值
- 例子：
  - `征税王冠`：拾取金币时叠短时伤害势能
  - `经验共鸣器`：拾取经验时短时获得范围和持续加成
  - `赏金符`：连续击杀会掉落强化金币，拾取后触发脉冲
  - `回收模块`：命中的投射物有概率返还为临时子弹数量

### 6. 遗物/终局类

- 作用：后期高辨识度的大道具
- 例子：
  - `硫磺圣柜`：激光类获得蓄能大束和副束折射
  - `日轮圣徽`：辉耀/圣经/圣剑的圣属性联动显著增强
  - `瘟疫圣坛`：毒、圣水、区域残留自动串联传播
  - `千刃御印`：飞刀、手里剑、斧头获得额外二段轨迹

## 与现有武器的推荐联动

### 激光

- `focus_lens + 月相透镜 + 硫磺圣柜`
- 方向：折射副束、束宽成长、命中叠焦

### 圣水

- `alchemist_flask + 炼成催化剂 + 瘟疫圣坛`
- 方向：区域反应、残留串联、中心拉拽

### 辉耀

- `pummarola + 余烬圣歌 + 日轮圣徽`
- 方向：贴脸灼烧、周期圣焰脉冲、压场推进

### 圣剑

- `hollow_heart + 血色回旋芯 + 审判印记`
- 方向：近战续航、回旋圣裁、暴击处决

### 火球

- `spinach + 诡雷火种 + 炼成催化剂`
- 方向：爆炸、残留、连锁燃爆

### 闪电

- `wings + 导雷骨针 + 反射晶片`
- 方向：移动导流、链雷回跳、感电扩散

## 终局联动示例

- `硫磺圣柜 + focus_lens + clover`
  - 激光暴击时分出弱化折射束
- `瘟疫圣坛 + alchemist_flask + holy_water`
  - 圣池之间形成感染链
- `日轮圣徽 + radiance + bible`
  - 圣环经过辉耀外圈时产生太阳耀斑
- `血契烙印 + whip + pummarola`
  - 连续吸血后触发血色大剑弧

## 实现顺序

### Phase 1

- 先补 6 个最容易接入的道具
- 原则：只改现有伤害链和投射体字段
- 推荐：
  - `反射晶片`
  - `炼成催化剂`
  - `审判印记`
  - `重力井`
  - `征税王冠`
  - `过载针剂`

### Phase 2

- 上 6 个联动器
- 让 build 形成明显“成型感”

### Phase 3

- 上 3 到 4 个遗物级大道具
- 做高视觉表现和终局 fantasy

## 风险控制

- `aura / area / orbit` 对高攻速道具必须继续有限幅
- 数量乘区和伤害乘区不要在同一道具上同时大幅叠加
- 联动优先改行为，不优先改纯倍率
- 新道具进入压测前必须过 AI 构筑测试
