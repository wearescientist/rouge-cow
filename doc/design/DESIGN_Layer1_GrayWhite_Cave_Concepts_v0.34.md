# DESIGN_Layer1_GrayWhite_Cave_Concepts_v0.34

## 一、任务目标

本稿只处理第一层 `菌丝区`，不扩散到其他楼层。

目标不是给第一层换一张更漂亮的地板，而是给它定义一个真正能支撑后续六层扩展的“样板空间”。

第一层必须同时满足：

- 保留白色菌丝 / 灰白洞穴的主题基因
- 适配当前四角可见的中心舞台视角
- 能承载移轴带来的微缩感
- 具备更强的电影感、空间层次和艺术感

---

## 二、共同约束

三套方案虽然结构不同，但必须遵守以下共同约束：

### 2.1 颜色约束

- 主体绝不走灰绿
- 正确方向是：骨白、灰白、灰褐、冷灰
- 允许少量冷蓝白孢子光
- 禁止温暖金黄主导

### 2.2 空间约束

- 核心玩法区仍是规则方形
- 外围氛围区不承担玩法
- 四角都必须成立，不能再像“补丁块”
- 门必须是空间阈值，而不是图标

### 2.3 光照约束

- 以冷暗洞腔为底
- 核心舞台仅略亮于外围
- 外围必须更暗、更虚、更安静
- 光照服务孢子、菌丝和裂膜门，不追求暖色神圣感

### 2.4 材质约束

- 地板：白菌丝覆盖的骨灰洞面
- 墙：骨质 / 菌丝混合洞壁
- 转角：厚实结构角，不再是平面角图
- 门：裂开的菌膜阈值或菌腔开口

---

## 三、方案 A：灰白圣盒舞台

### 3.1 定位

最稳的样板方案。  
保留你当前房间结构的可读性，把它升级成“被菌丝吞没的骨质匣体”。

### 3.2 画面结构

- 核心方形舞台占画面约 `62%`
- 四壁厚重，像围住舞台的菌骨盒壁
- 四角为厚实结构角块，像被菌丝堆叠的骨性结节
- 上下门位像菌膜裂口，嵌在厚壁中

### 3.3 材质表达

- 地板：灰白菌丝丝束横向蔓延，底材像骨灰混岩
- 墙体：偏骨质的硬结构外壳，表面有少量菌丝包覆
- 转角：比墙更厚、更暗，承担房间稳定感
- 门：像裂开的菌膜或被挤开的洞腔口

### 3.4 前后景设计

- 前景：下方两角有少量失焦菌丝帘和碎石
- 后景：上方门外有更深的灰白洞腔与微弱孢子光
- 侧景：左右仅保留较轻的洞壁包裹感

### 3.5 光照语言

- 中央冷白弱亮
- 边缘灰冷压暗
- 门口附近有极轻的远处微光
- 孢子光只做气息，不做主光源

### 3.6 优点

- 最容易先做成
- 与现有系统兼容性最高
- 适合当整个六层体系的结构母版

### 3.7 风险

- 如果细节太保守，会接近“高级版当前房间”

---

## 四、方案 B：菌丝标本箱

### 4.1 定位

最能拥抱移轴和微缩感的方案。  
房间像被封存的洞穴标本，玩家在其中活动，镜头像在看一个活的微缩展柜。

### 4.2 画面结构

- 核心方形舞台占画面约 `56%`
- 外围氛围框景更宽
- 下方前景遮挡比方案 A 更明确
- 上方有更远的洞腔背景，像标本箱背后的世界延伸

### 4.3 材质表达

- 地板：菌丝与粉尘感更明显，表面更像被长期封存的灰白有机层
- 墙体：不像建筑墙，而像洞腔切面
- 转角：更圆、更有生长感，像菌丝与骨质自然堆积
- 门：像被撕开的活体膜层，不是规则门框

### 4.4 前后景设计

- 前景：下方有明显的模糊菌丝幕、枝状根、碎骨
- 后景：上方是更深的菌腔层与漂浮孢子
- 侧景：左右可加入斜插的石笋或洞壁断面

### 4.5 光照语言

- 中央更柔、更薄的冷亮区
- 外围暗部更明显，但过渡更自然
- 孢子微光和门外微光更有空气感
- 模糊服务“被观看的标本空间”

### 4.6 优点

- 艺术感最强
- 最适合你当前的移轴语言
- 更容易做出“像电影场景”的气氛

### 4.7 风险

- 过度会削弱地下城感，像展览盒

---

## 五、方案 C：灰白圣所裂腔

### 5.1 定位

最接近《八方旅人》高级空间感的方案。  
不是神殿，而是“洞穴中的仪式性裂腔”，带一点伪等距圣所气质。

### 5.2 画面结构

- 核心方形舞台占画面约 `60%`
- 四角有更明确的斜切折面
- 墙与转角关系更像结构面交汇
- 门位更像祭坛裂口或洞宫入口

### 5.3 材质表达

- 地板：灰白菌丝沿着中轴和边界组织，秩序感更强
- 墙体：骨质硬壳与菌丝纹交替，较少松散杂物
- 转角：像洞宫折面节点，比 A 更精致，比 B 更结构化
- 门：像裂开的骨膜拱口

### 5.4 前后景设计

- 前景：较克制，只保留少量模糊遮挡
- 后景：更强调门外深处的洞腔秩序和光的引导
- 侧景：左右洞壁更像被雕塑过的骨质结构

### 5.5 光照语言

- 中景主体更清晰
- 周围暗部更稳
- 门外远处有轻微冷白引导光
- 整体更像“被构图过的圣所裂腔”

### 5.6 优点

- 最有高级 JRPG 空间感
- 最容易拉出“艺术化洞穴”的格调
- 适合作为后续 Boss 房与最终层的结构预演

### 5.7 风险

- 设计门槛最高
- 如果角块和墙体不到位，会变成“半等距但不够真”

## 七、当前推荐

如果只选一个“先落地最稳”的方向，推荐：

### 推荐主案：A + B 混合

即：

- 结构骨架用 `灰白圣盒舞台`
- 气氛和前景遮挡借 `菌丝标本箱`

原因：

- A 保证可落地
- B 提供移轴和电影感的解释力
- 两者结合最适合你当前项目阶段

### 推荐副案：A + C 混合

当第一版结构稳定后，可以把：

- 转角折面
- 门的圣所感
- 更精致的墙体主次

从 C 方案逐步引入

---

## 八、第一层样板最小可交付范围

如果进入正式样板阶段，第一版不要一口气做满。  
建议最小范围只包含：

1. 缩小核心方形舞台
2. 灰白菌丝地板
3. 厚实转角
4. 裂开的菌膜门
5. 下方轻前景遮挡
6. 上方门外洞腔与微孢子光

只要这六件事成立，第一层就已经能比现在高一个档次。

## 九、并入完整镜头后的样板约束

在 `DESIGN_FullScene_16x9_CoreArena_v0.34` 确认后，第一层样板需要再追加以下约束：

### 9.1 镜头关系

- 整个 `16:9` 都是第一层洞穴世界，不再允许 HUD 外侧出现未设计空边
- 中央核心舞台只承担玩法判定，不再承担全部构图职责
- 上下左右必须各自承担明确景别功能，而不是统一当成“外围装饰”

### 9.2 第一层的四周翻译

- 上方：更深的灰白菌腔、远处冷白微光、少量漂浮孢子
- 下方：失焦菌丝帘、碎骨、洞缘模糊遮挡
- 左右：骨质洞壁切面与少量菌丝黏连层
- HUD 后方：更安静、更暗、更低频，不放主高光与最强纹理

### 9.3 本轮合并后的判断标准

- 玩家第一眼应先读到“完整洞穴镜头”，再读到中心规则舞台
- HUD 应该像压在世界上，而不是压在一块中心房间外的空壳上
- 第一层色相必须继续锁定在灰白、骨白、灰褐、冷灰，不能因为外围扩展重新滑回灰绿

### 9.4 样板落地顺序

1. 先弱化中心硬边框感，防止画面退回“高级版旧房间”
2. 再建立 HUD 后方缓冲带，保证信息可读性
3. 最后补强四周洞腔和菌丝前后景，让完整镜头真正成立
