## 二、设计目标

### 核心原则
1. **沉浸式体验**：UI不出戏，与游戏世界融合
2. **响应式布局**：适配不同尺寸的贴图
3. **统一风格**：全部采用暗黑地下城/腐蚀风格
4. **渐进迁移**：不破坏现有功能，分阶段实施

### 视觉风格定义
- **主色调**：深灰色背景 + 金色/红色装饰
- **边框样式**：金色花纹装饰 + 暗色石质纹理
- **字体**：微信通用的黑体/粗体

## 四、分阶段实施计划

### 第一阶段：顶部HUD贴图化 (2-3天)
**目标**：用Canvas重写顶部状态栏

| 原有元素 | 新实现 | 贴图资源 |
|---------|--------|----------|
| 生命值文字 | 贴图血条+数字 | `ui_bar_hp_bg.png` + `ui_bar_hp_fill.png` + 心形图标 |
| 经验条简单色块 | 贴图经验条 | 需新增 |
| 金币emoji | 贴图金币+数字 | `ui_icon_coin.png` |
| 武器列表 | 贴图格子 | `ui_slot_weapon.png` |

**API设计**:
```javascript
// HUDRenderer.js
class HUDRenderer {
    constructor(spriteManager) {
        this.sprites = spriteManager;
        this.layout = {
            hpBar: { x: 20, y: 15, width: 200, height: 24 },
            expBar: { x: 20, y: 42, width: 200, height: 8 },
            coinIcon: { x: 240, y: 15, size: 28 },
            weaponSlots: { x: 20, y: 65, count: 6, size: 40 }
        };
    }
    
    draw(ctx, player) {
        this.drawHealthBar(ctx, player);
        this.drawExpBar(ctx, player);
        this.drawCoinLabel(ctx, player.gold);
        this.drawWeaponSlots(ctx, player.weapons);
    }
}
```

## 五、关键技术点

### 1. 贴图裁刍策略
由于原始贴图尺寸很大（1024x1024），需要根据使用场景裁剪：

```javascript
// 从large texture中裁剩需要的部分
const SPRITE_REGIONS = {
    hpBar: { sx: 0, sy: 400, sw: 1024, sh: 224 },  // 只取中间血条部分
    heartIcon: { sx: 100, sy: 100, sw: 824, sh: 824 },
    coinIcon: { sx: 100, sy: 100, sw: 824, sh: 824 }
};
```

```css
}
```

## 六、风险与应对

| 风险 | 影响 | 应对方案 |
|-----|------|---------|
| 贴图加载延迟 | 首次进入界面闪烁 | 预加载机制 + loading屏幕 |
| 贴图分辨率不匹配 | 模糊或销锋 | 使用多倍图或向量图 |
| 性能下降 | 帧率降低 | Canvas离屏渲染优化 |
| 缓存问题 | 新贴图不生效 | 版本号管理 |
