# 武器升级系统 v0.16.0 设计文档

## 设计理念（参考吸血鬼幸存者）

### 核心原则
1. **每级都有可见提升** - 不只是数值，还有数量/范围/持续时间等视觉变化
2. **关键质变节点** - 第4级和第8级是关键质变节点，带来机制上的重大变化
3. **超武是质变** - 超武不是简单的数值增加，而是机制上的彻底改变

## 技术实现说明

### 升级应用流程
1. 武器等级提升时调用 `applyUpgrade(weapon, newLevel)`
2. 从 `WEAPON_UPGRADE_TABLE` 查找对应武器的升级数据
3. 应用数值提升（dmg/range/speed等）
4. 应用机制改变（count/pierce/split等）
5. 记录升级历史用于UI展示

### 新机制实现
- **延迟攻击**：通过 bullet.delay 字段实现
- **双重/三重攻击**：通过创建多个投射物实现
- **弹跳**：bullet.bounce 字段 + 碰撞后寻找新目标
- **分裂**：命中时创建子投射物
- **连锁**：击中后寻找范围内最近敌人继续攻击
- **即死**：伤害计算前检查血量百分比
- **吸血**：造成伤害时按比例回血

### UI展示
- 升级选择界面显示下一级的具体效果描述
- 武器图标旁显示等级和升级类型图标
- 满级武器有特殊视觉标识
