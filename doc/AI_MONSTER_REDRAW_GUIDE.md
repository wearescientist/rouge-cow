# 怪物贴图重绘需求文档

## 项目背景
肉鸽牛牛游戏需要重新绘制所有怪物贴图，使其风格与玩家角色统一。

## 参考标准：玩家角色风格分析

### 玩家贴图位置
`assets/sprites/player/variants_40x40/player_idle_0_crop_40.png`

### 玩家风格特征

| 特征 | 描述 | 具体要求 |
|------|------|----------|
| **分辨率** | 低像素 | 画布约40-60px，有效内容30-40px |
| **像素感** | 块状像素 | 像素边缘清晰不模糊，拒绝抗锯齿过度柔化 |
| **细节密度** | 低 | 不要太多小细节，大色块为主 |
| **边缘处理** | 柔和但不糊 | 有1-2px的轻微抗锯齿，不是锐利的矢量边缘 |
| **明暗对比** | 中等偏低 | 不要高对比度，明暗过渡柔和 |
| **饱和度** | 中等偏低 | 颜色不要太鲜艳，略带灰度 |
| **光影** | 简单统一 | 单一光源，柔和阴影，不要复杂高光 |
| **轮廓** | 清晰可读 | 剪影要能一眼认出是什么 |

### 视觉参考关键词
- "Cinematic pixel art" (电影感像素)
- "Low-res sprite" (低分辨率精灵)
- "Soft shading" (柔和阴影)
- "Limited palette" (有限色板)
- "PS1 era graphics" (PS1时代风格)

## 当前怪物问题

### 问题1: 细节过多
- 现在的怪物有太多小纹理、小装饰
- 看起来像"高清贴纸"而不是"游戏精灵"

### 问题2: 对比度过高
- 边缘太锐利
- 高光和阴影太强烈
- 看起来像矢量图而不是像素图

### 问题3: 分辨率不匹配
- 怪物贴图尺寸不一
- 有些太大(100px+)，有些太小
- 需要统一在40-60px范围

## 重绘要求

### 技术要求

```
画布尺寸: 48x48px 至 60x60px
有效内容: 30-45px (不要撑满画布)
帧数: 每怪物4帧 (f01, f02, f03, f04)
格式: PNG，透明背景
命名: f01.png, f02.png, f03.png, f04.png
```

### 艺术要求

1. **降维处理**
   - 把细节减少50%
   - 合并小色块
   - 用暗示代替描绘

2. **边缘软化**
   - 所有边缘加1px半透明过渡
   - 不要硬边
   - 不要锯齿状像素边缘

3. **色彩调整**
   - 饱和度降低20%
   - 明度对比降低30%
   - 阴影区域加一点点蓝/紫

4. **统一光影**
   - 所有怪物：光源从左上方45度
   - 阴影在右下方
   - 阴影边缘柔和

### 按类型处理建议

#### 飞行类 (蝙蝠、鸟、蜜蜂)
- 翅膀简化：不要羽毛细节，用2-3个色块表示
- 身体圆润：不要棱角
- 轻微上下浮动感

#### 爬行类 (蛇、蜗牛)
- 身体曲线流畅
- 分段感减弱
- 蜗牛壳：简化螺旋，2-3个色阶

#### 四足类 (狐狸、豹、兔子)
- 四肢简化：短粗，不要关节细节
- 头部占身体1/3
- 大眼睛，可爱风格

#### 宝箱怪
- 箱子棱角圆化
- 牙齿简化：3-4个三角形
- 舌头用1个色块

#### 幽灵类
- 下半身虚化：半透明像素渐变
- 没有脚：底部渐隐
- 简单面部表情

#### 昆虫类
- 腿减少：4条可见即可
- 身体分段：用颜色区分，不要画关节
- 触角简化：2像素粗线条

## 质量检查清单

每个怪物完成后检查:

- [ ] 尺寸在40-60px范围
- [ ] 和玩家贴图放一起风格统一
- [ ] 减少细节，大色块为主
- [ ] 边缘柔和但不模糊
- [ ] 明暗对比度适中
- [ ] 4帧动画连贯
- [ ] 背景透明

## 示例对比

### 不要这样 (当前问题):
- 100x100px画布
- 20+个小细节
- 锐利边缘
- 高饱和度
- 复杂光影

### 要这样 (目标风格):
- 48x48px画布
- 5-8个大色块
- 柔和边缘
- 中等饱和度
- 简单光影
- 像玩家一样"可爱+电影感"

## 批次安排

建议分批处理:
1. **第一批**: 第1层全部 (18个) - 测试风格
2. **第二批**: 第2-3层 (23个) - 确认风格
3. **第三批**: 第4-6层 (28个) - 完成

每批完成后先测试1-2个在游戏中效果，再全部生成。
