# 完整武器属性表 v0.16.1

## 属性说明

| 属性 | 说明 | 单位 |
|------|------|------|
| dmg | 基础伤害 | 点 |
| cd | 冷却时间 | 秒 |
| range | 攻击距离/范围 | 像素 |
| speed | 弹道速度 | 像素/秒 |
| count | 投射物数量 | 个 |
| pierce | 穿透次数 | 次 |
| duration | 持续时间 | 秒 |
| subtype | 弹道类型 | - |
| homing | 追踪强度 | 0-1 |

## 🔧 优化建议

### 1. 数值平衡问题

**问题1: 飞刀和手里剑DPS过高**
- 飞刀Lv8 DPS 1285，是其他武器的5-10倍
- **建议**: 降低burst成长，Lv8 burst从15降到10

**问题2: 镰刀DPS提升过低**
- Lv1→Lv8只提升88%，缺乏吸引力
- **建议**: 增加即死伤害加成，或提高基础伤害成长

**问题3: 毒镖直接伤害过低**
- 全程只有15点伤害，过于依赖中毒
- **建议**: 提高基础伤害到20-25

### 2. 机制问题

**问题4: 部分武器缺乏质变**
- 冰锥Lv4-Lv8只有数值提升
- **建议**: Lv6添加冻结范围扩大

**问题5: 超武提升不一致**
- 魔杖超武CD 0.6→0.08，提升7.5倍
- 火球超武CD 1.4→1.0，提升仅40%
- **建议**: 统一超武提升幅度在200%-500%

### 3. 属性缺失

**问题6: 缺少弹道大小配置**
- 没有 projectileSize 属性
- **建议**: 添加 size 属性，范围 0.5-2.0

**问题7: 缺少命中效果差异化**
- 所有武器只有伤害，缺乏视觉效果区分
- **建议**: 添加 hitEffect 属性（爆炸、冰冻、流血等）

### 4. 建议调整表

| 武器 | 当前问题 | 建议调整 |
|:----:|:---------|:---------|
