# PLAN_Weapon_Rework_v1

## 目标

- 将 `whip` 的语义与表现替换为“圣剑”，保留内部 key 以降低存档和调用链风险
- 将武器与进化被动改为严格 `1:1`
- 被动效果保持“通用或部分通用”，不做只能服务单一武器的纯专属废属性
- 强化武器差异化，避免“升级 = 加数量 / 加伤害 / 减 CD”的同质化路线
- 重做激光成长与超武行为，普通激光主成长改为粗度与持续时间，超武改为曲线追踪贯穿

## 升级差异化原则

- 圣剑：强化弧宽、斩击长度、圣痕斩光，不走“多段数量堆叠”
- 镰刀：强化外圈范围、处决阈值、回旋斩
- 魔杖：强化追踪转向、锁敌稳定性、连发节奏
- 飞刀：强化射速、穿透、暴击效率
- 斧头：强化回旋距离、返回重击、双段命中
- 十字架：强化弹跳、回返轨迹、暴击光斩
- 火球：强化爆炸半径、二次裂爆、燃烧蔓延
- 手里剑：强化散射角、回收、切割频率
- 冰锥：强化冻结率、冻结时长、碎裂波及
- 激光：强化粗度、持续时间、持续命中频率
- 毒镖：强化毒层、扩散、宿主传播
- 圣经：强化环绕半径、转速、命中频率
- 闪电：强化链数、链距、感应分叉
- 圣水：强化水池半径、持续时间、残留污染
- 辉耀：强化领域半径、灼烧层、压制感

## 激光改造规格

### 普通激光

- 不再通过升级增加激光数量
- 主要成长参数：
  - `width`
  - `life`
  - `tickCooldown`
- 体验目标：从细束点射成长为粗束压制

### 超武激光

- 改为单束高强度主激光
- 默认沿玩家移动方向喷射
- 仅在限定追踪角内自动朝最近敌人弯折
- 保持贯穿，视觉参考“硫磺火 + 自动追踪”
- 技术实现采用折线段路径，不上高成本曲面碰撞

## 实施步骤

1. 先修改武器/被动/进化表与命名语义
2. 再修改 `Weapon` 中的升级曲线与激光发射参数
3. 再修改 `updateLaserBullet()` 的曲线路径与碰撞
4. 最后修改 `WeaponVisuals` 的圣剑近战表现与曲线激光渲染

## 风险点

- `whip` key 保留，外观改为圣剑，避免打断旧调用链
- 新被动需要接入 `PassiveManager.getStats()`
- 激光需要同时修改发射、更新、渲染三处，否则功能会脱节
