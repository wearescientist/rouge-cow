## 四、资源需求

### 人力
- 主程序员: 1人 (全职)
- 辅助开发: 1人 (半职)

### 时间
- 总工期: 12周
- 并行开发: 可压缩至 8周

### 技术栈
```
开发:
├── Vite (构建工具)
├── TypeScript (类型安全)
├── ESLint + Prettier (代码规范)
└── Vitest (单元测试)

AI/平衡:
├── Node.js (模拟器)
├── Genetic Algorithm (参数优化)
└── Data Analysis (报告生成)
```
