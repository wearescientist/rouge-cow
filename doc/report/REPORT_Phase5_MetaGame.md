## 实现概述

Phase 5 完成4个元游戏系统，显著提升长期可玩性和玩家留存。

### 5.1 解锁系统 (UnlockSystem.js)
**代码量:** 18KB

**核心功能:**
- 6个职业解锁（战士初始，其他通过游戏进度解锁）
- 5个武器解锁（镰刀、回旋镖、拳套等）
- 5个被动解锁（吸血鬼、凤凰、忍者等）
- 4个宠物解锁（幼龙、独角兽、机械助手等）
- 4个难度解锁（简单/普通/困难/噩梦/不可能）
- 3个模式解锁（每日挑战、无尽模式、Boss连战）

**解锁条件类型:**
| 类型 | 说明 |
|------|------|
| reachFloor | 到达指定层数 |
| killCount | 累计击杀数 |
| winCount | 通关次数 |
| noDamageBoss | 无伤击败Boss |
| collectItems | 收集物品 |
| criticalKills | 暴击击杀 |

### 5.2 难度系统 (DifficultySystem.js)
**代码量:** 16KB

**难度等级:**
| 难度 | 敌人生命 | 敌人伤害 | 分数倍率 | 特色 |
|------|----------|----------|----------|------|
| 简单 | 0.7x | 0.6x | 0.5x | 2次免费复活 |
| 普通 | 1.0x | 1.0x | 1.0x | 标准体验 |
| 困难 | 1.5x | 1.5x | 1.5x | 精英怪+30% |
| 噩梦 | 2.2x | 2.0x | 2.5x | 传说掉率+ |
| 不可能 | 3.5x | 3.0x | 5.0x | 永久死亡 |

**技术特点:**
- 动态敌人属性修正
- Boss额外技能（噩梦+）
- 奖励倍率同步调整
- 解锁条件追踪

### 5.3 每日挑战系统 (DailyChallengeSystem.js)
**代码量:** 15KB

**核心功能:**
- 每日随机种子生成
- 14种挑战修正（正面/负面/特殊）
- 分数排行榜（模拟）
- 历史记录保存

**修正类型示例:**
| 修正 | 类型 | 效果 |
|------|------|------|
| 玻璃大炮 | 混合 | 伤害x2，生命x0.5 |
| 无限火力 | 正面 | 攻速+50% |
| 无治疗 | 负面 | 无法恢复生命 |
| 近战专精 | 特殊 | 只能使用近战武器 |
| 虫群模式 | 混合 | 敌人x3，生命x0.5 |

### 5.4 剧情系统 (StorySystem.js)
**代码量:** 23KB

**核心功能:**
- 主线剧情（6层探索叙事）
- Boss背景故事
- 4种结局（净化/牺牲/统治/真结局）
- 4个记忆碎片（环境叙事）

**剧情分类:**
| 类别 | 数量 | 说明 |
|------|------|------|
| 主线 | 6 | 每层探索剧情 |
| Boss | 4 | Boss背景故事 |
| 结局 | 4 | 不同通关方式 |
| 记忆碎片 | 4 | 收集品叙事 |

**结局条件:**
- **净化**: 标准通关
- **牺牲**: 选择与Boss融合
- **统治**: 取代Boss成为新主宰
- **真结局**: 收集全部记忆碎片后触发

## 文件结构

```
src/systems/
├── UnlockSystem.js         (18KB) - 解锁系统
├── DifficultySystem.js     (16KB) - 难度系统
├── DailyChallengeSystem.js (15KB) - 每日挑战
└── StorySystem.js          (23KB) - 剧情系统
```

---

## 系统交互

```
UnlockSystem ──解锁──→ DifficultySystem (难度解锁)
      │                    ↓
      └─────────────→ DailyChallengeSystem (模式解锁)

StorySystem ──结局──→ UnlockSystem (内容解锁)
      │
      └─记忆碎片─→ 真结局条件检查

DifficultySystem ──通关──→ 所有系统数据保存
```

---

## 数据持久化

所有系统均支持 localStorage 保存:

```javascript
rougeCow_unlocks    // 解锁进度
rougeCow_difficulty // 难度通关次数
rougeCow_daily      // 每日挑战历史
rougeCow_story      // 剧情解锁状态
```
