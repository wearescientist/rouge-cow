# 调试工作台接入报告

## 本次实现

- 新增 `tools/debug_workbench.html` 作为统一网页工具入口
- 新增 `tools/debug_workbench.js` 作为工具注册表与布局状态管理层
- 已接入当前 `tools/` 下主要 HTML 工具，以及 `tools/editor/index.html`
- 支持本地拖拽排序、隐藏、删除、恢复、搜索、分类筛选、自定义临时入口

## 设计边界

- 本次不改现有工具内部逻辑，只做统一入口层
- 删除仅作用于本地工作台布局，不删除真实文件
- 布局状态存储在浏览器 `localStorage`

## 后续扩展位

- 怪物总控台：等级、基础属性、房间分布、贴图选择、新增怪物
- 房间分布编辑器：怪物池、事件权重、Boss 规则
- 资源选择器：贴图预览、帧检查、路径回填

## 风险规避

- 采用独立页面，避免影响主游戏运行时
- 采用静态注册表，避免扫描文件系统带来的路径不稳定
- 采用相对链接，兼容当前本地工具页访问方式
