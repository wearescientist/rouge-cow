# REPORT_Weapon_Audit_v1

## 目标

- 复查武器数量成长、倍率成长、超武收益是否异常
- 复查被动是否存在“必拿”或“几乎没人拿”的失衡问题
- 为后续道具联动提供平衡基线

## 武器侧结论

- `十字架` 仍处于头部强势，清群和超武爆发都很高，允许保留为高峰值武器
- `闪电` 的问题不是单纯太强，而是成长过多依赖 `count + chain + branches` 堆叠，机制辨识度被数量放大掩盖
- `手里剑 / 飞刀 / 十字架` 的后期数量成长偏显性，容易挤占其他成长轴
- `圣经 / 圣水` 的核心矛盾在命中密度与压场存在感，不是简单基础伤害不足
- `辉耀 / 圣剑 / 镰刀` 这类短手武器更依赖手感，之前的问题主要是命中半径和可操作空间偏短

## 被动侧结论

### 偏强

- `duplicator`：过于通用，原本每级 `+1` 容易成为多数构筑的必拿
- `empty_tome`：乘法 CD 缩减收益过硬
- `spinach`：稳定强，被大多数构筑无脑接受
- `candelabrador`：在短手武器整体拉长后，泛用价值进一步上升

### 偏弱

- `crown`：仅有经济收益，战斗爽点不足
- `wings`：只有移速，战斗体感弱
- `attractorb`：更偏便利性，不够像战斗构筑件
- `armor`：若没有反击反馈，选取感偏虚
- `focus_lens / alchemist_flask`：方向正确，但需要更明确的联动收益来证明选取价值

## 本轮平衡原则

- 不追求所有武器和被动数值接近平局
- 允许武器偏科，保留各自强场景与弱点
- 被动尽量保持通用，但需要明确“为什么值得拿”
- 通过联动补足 T2 被动的爽点，而不是单纯堆面板

## 第一轮执行方向

- 下调 `duplicator / empty_tome / candelabrador` 的泛用强度
- 稳定 `spinach`，保留其通用输出定位
- 给 `crown / wings / attractorb / armor` 增加战斗侧联动价值
- 给 `focus_lens / alchemist_flask` 增加可视化联动收益

## 联动落地优先级

优先实现四组：

- `focus_lens + clover`：聚焦折射
- `alchemist_flask + spinach`：炼成反应
- `pummarola + armor`：血甲反震
- `crown + attractorb`：王权拾取势能
