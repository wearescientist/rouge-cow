# 升级10 - 墙门系统重构报告 (迭代21-25)

## 完成时间
2026-02-22

## 问题分析
用户反馈墙和门"不对劲"，经分析发现：
1. **门形状不一致**: 上下门是100x120矩形，左右门是120x100矩形
2. **贴图不连续**: 墙贴图旋转后导致砖块排列错位
3. **渲染复杂**: 左右墙需要旋转tile，增加了复杂性

## 解决方案

### 统一规格
| 元素 | 原规格 | 新规格 |
|:---|:---|:---|
| 墙厚度 | 120px | 120px (统一) |
| 门大小 | 100x120 / 120x100 | 100x100 (正方形) |
| 门位置 | 贴边 | 墙内居中 |
| 贴图方式 | 旋转/翻转 | 直接平铺 |

### 门在墙内的位置
```
墙厚度: 120px
门大小: 100px
门偏移: (120-100)/2 = 10px

上墙: y=10~110 (门在墙中间)
下墙: y=height-110~height-10
左墙: x=10~110
右墙: x=width-110~width-10
```

## 代码改动

### 1. 门大小统一 (迭代23)
```javascript
// 统一门为正方形 100x100，在墙厚120内居中
const doorSize = 100;
const doorOffset = (wallT - doorSize) / 2; // 10px

case 'up': 
    doorX = this.centerX - doorSize/2; 
    doorY = doorOffset; // 10px
    doorW = doorSize; 
    doorH = doorSize; 
    break;
// ... 其他方向类似
```

### 2. 墙分段绘制 (迭代24)
原来：整面墙绘制后用地板色"挖洞"
现在：绘制时分段跳过门区域

```javascript
// 上墙 - 分左右两段（跳过中间的门）
if (viewLeft < doorLeft) {
    // 绘制左段墙
}
if (viewRight > doorRight) {
    // 绘制右段墙
}
```

### 3. 简化贴图渲染
原来：左右墙需要旋转tile 90度
现在：所有墙直接平铺正方形贴图，无需旋转

## 优势
1. **贴图连续**: 砖块排列整齐，无错位
2. **逻辑简单**: 无需翻转/旋转逻辑
3. **视觉统一**: 四面墙外观一致
4. **性能更好**: 减少旋转计算
