# REPORT_HUD_FloorTexture_Blend_v0.33

## 时间
- 2026-03-08 16:15

## 本次调整
- 为 1 到 6 层新增 HUD 侧栏地板贴图主题变量，左右侧栏改为跟随当前层使用对应地板纹理
- 侧栏背景增加暗化、边缘压暗与轻模糊处理，避免原始地板直接平铺后干扰文字和数值可读性
- 左右 HUD 卡片统一改为更轻的半透明材质，保留边框和层级，但减少“独立 UI 面板”割裂感
- 保持心形血条、经验条和小地图语义色稳定，仅让整体材质和雾色跟随楼层变化

## 风险自检
- 避免直接使用原图高对比平铺，降低信息噪声过高导致的 HUD 可读性下降
- 保留 `applyFloorHudTheme()` 作为唯一楼层主题入口，避免桌面 HUD、小地图和侧栏背景出现不同步
- 使用真实资源路径 `assets/sprites/tiles/floors/`，避免主题切换后背景丢失
