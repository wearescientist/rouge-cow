# REPORT 隐藏房光场与荧光蠕虫修复

## 本次改动
- 关闭隐藏房中的旧 `SimpleLighting` multiply 光照，避免整屏二次压灰。
- 强化 `RoomBlurSystem` 对隐藏房线索光源的 reveal / bloom / colorize 权重。
- 为隐藏房补充统一环境光源：一层左右装置区、二层蠕虫区、三四层中心、六层遗产桌。
- 强化二层蠕虫的本体发光、地面冷光池、红虫信息高亮、黑兔演示发光。
- 强化一层模板板的装置感，增加左右面板与格位底板。
- 六层接入 `desk.png` 桌子素材，改善遗产房桌面构图。

## 重点风险控制
- 没有改动谜题完成条件与通关状态结构。
- 没有改动隐藏房交互键位与 true ending 判定入口。
- 没有修改非隐藏房的主渲染顺序，仅在隐藏房分支做增强或关闭旧光照。

## 建议回归点
- 1层：模板区/蜡烛区是否都有明确地面光池与更清楚的 2x4 结构。
- 2层：普通虫、红虫、黑兔在黑暗区域是否都能稳定读出来。
- 4层：投影房未完成时蓝色投影光是否过亮。
- 6层：桌子素材位置、书/面包/钱袋遮挡关系是否自然。

## 追加更新（cinematic pass）
- 修复 `HiddenRoomSystem.js` 后半段重复定义导致的隐藏房装饰光、环境光、漂浮尘埃被覆盖失效问题。
- 恢复并增强所有隐藏房的 `buildFloorDecor` 主链路，让各层重新拥有统一的基底动机光。
- 隐藏房主暗层进一步压深，降低玩家存在光，减少灰雾感；同时提高 bloom 保留，改成更接近黑底局部发光。
- `hiddenLightSources` 正式吃 `hiddenScale`，让一层左右装置光、二层虫群舞台光、六层桌面暖光真正放大生效。
- 修正运行时生效的二层 `drawFloor2Critters` 版本，避免后半段旧定义把更亮的虫体绘制覆盖掉。
- 同步隐藏房标题：1层平移复刻房、2层异色蠕虫房、4层投影记忆房。
