# REPORT 隐藏房布局编辑器素材库与鼠标修复 2026-03-21

## 目标
- 让隐藏房布局编辑器先导入素材到素材库，再从素材库反复实例化同一素材。
- 修复鼠标拖拽不可用的问题，降低对键盘操作的依赖。
- 缩短调试面板长度，避免隐藏房编辑区把整个测试面板拉得过长。

## 本次改动
- `src/systems/HiddenRoomSystem.js`
  - 新增运行时素材库与按楼层存放的自定义装饰实例。
  - 支持本地多图导入与目录批量导入。
  - 同一素材可多次放置，生成多个 `custom_decor` 实例。
  - 自定义装饰接入现有 `hiddenDecor` 绘制链路，不影响既有谜题节点。
  - 鼠标交互改为左键选中拖拽、滚轮缩放，并保留键盘作为辅助。
  - 新增删除选中装饰、清空当前楼层已放置自定义装饰。
- `src/systems/DebugPanel.js`
  - 隐藏房布局编辑区改为可折叠。
  - 在调试面板中追加素材库列表。
  - 每个素材提供“放置 1 个 / 放置 5 个”入口。
  - 增加“删除选中装饰 / 清空已放置”按钮。

## 验证
- `node --check src/systems/HiddenRoomSystem.js`
- `node --check src/systems/DebugPanel.js`

## 已知边界
- 本地导入素材当前是运行时素材库，适合当前会话内摆放与调试。
- 自定义素材本身没有接光，后续等用户摆位稳定后再统一补光。
