# 场景美术工作台接入报告

## 本次实现

- 新增 `tools/scene_art_workbench.html`
- 新增 `tools/scene_art_workbench.js`
- 接入总工作台 `tools/debug_workbench.html`

## 第一版能力

- 资源库：外壳、地板、门、墙体、边角、装饰、前景
- 画布操作：插入资源、拖拽移动、拉伸缩放、旋转
- 图层：外壳 / 地板 / 门 / 墙体 / 装饰 / 前景
- 辅助线：网格、实际区域、门区域、墙边界、构图框
- 调色：亮度、对比度、饱和度、色相、透明度、Tint
- 导出：布局 JSON 导出 / 导入 / 复制

## 第二轮校正

- 接入真实运行时参数：`VIEW 1920x1080`、`ROOM 2000x2000`、`WALL 120`、`DOOR 180`
- 将房间按正方形投影到 16:9 视口中，外壳与房间内资源分开坐标空间
- 新增本地素材导入，可手动选择本机图片加入资源库
- 新增中央玩家参考，使用真实玩家 40px 比例作为场景设计尺

## 第三轮重构

- 将页面重构为“资源 / 图层 / 已用素材 + 中央大画布 + 右侧检查器”的编辑器式布局
- 新增多选、框选、拖拽吸附、对齐线、图层显隐/锁定、层级前后调整
- 画布支持拖素材入场、直接移动、右下缩放、顶部旋转、键盘微调、快捷复制删除
- 资源流补上“本地图片导入 -> 进入资源库 -> 当前图层坐标空间落位”
- 导出区保留 JSON 导入导出，方便后续和正式运行时建立协议

## 第四轮优化

- 新增 `Alt + 拖拽` 直接复制并移动，减少重复摆件成本
- 已用素材区支持“一键再次插入”和“按类别筛回资源库”
- 图层增加透明度滑杆，对象属性增加混合模式选择
- 新增“聚焦选中”按钮，快速把当前对象拉回视口中心

## 第五轮校准

- 废弃“16:9 主画布”假设，改为对齐真实运行时的 `960 x 960` 正方形主画布
- 房间外框改为完整映射 `2000 x 2000` 世界房间，中央不再额外塞伪 16:9 框
- 将参考线拆成：房间外框、墙厚区、地板有效区、门逻辑区、门贴图区
- 玩家参考继续固定在房间中心，默认舞台也改为围绕正方形主画布构图

## 设计边界

- 当前是“场景合成工作台”，不是完整 PS
- 不直接写回运行时场景逻辑，只负责可视化设计与布局数据
- 第一版优先保证搭图效率，暂未加入蒙版、笔刷、复杂裁切

## 后续建议

- 下一轮优先补“多选群组等比缩放、Alt 拖拽复制、图层透明度、混合模式”
- 再下一轮再接“最近素材 / 已用素材复用 / 正式运行时布局协议”
