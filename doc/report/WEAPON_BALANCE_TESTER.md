# AI武器平衡测试系统

**版本**: v0.26  
**功能**: 自动化武器性能评估与平衡建议

---

## 使用方法

### 1. 运行测试

在游戏中按 `~` 打开调试面板，找到 **🤖 AI平衡测试** 区域：

- **⚡ 运行测试** - 开始所有武器的平衡测试
- **📊 导出报告** - 导出HTML格式详细报告

### 2. 测试过程

测试系统会模拟：
- 100次战斗场景
- 60秒标准时长
- 50个混合敌人
- 所有14种武器各自测试

### 3. 输出结果

测试完成后显示：
- 平衡分数 (0-100)
- S级/D级武器数量
- 推荐调整方案

---

## 测试原理

### 模拟计算

```
DPS = 总伤害 / 测试时长
理论DPS = 伤害 / CD
实际DPS = DPS × 命中率 × 特殊效果
```

### 武器类型处理

| 类型 | 模拟方式 | 说明 |
|:---|:---|:---|
| melee | 扇形范围命中3个 | 考虑范围和攻击角度 |
| proj | 投射物追踪 | 考虑穿速、弹跳、爆炸 |
| orbit | 环绕持续伤害 | 考虑持续时间和范围 |
| instant | 即时命中 | 考虑距离和连锁 |
| area | 区域持续伤害 | 考虑持续时间和慢效果 |
| aura | 光环伤害 | 考虑触发频率 |

## 平衡分级

| 等级 | DPS比例 | 说明 | 建议 |
|:---|:---:|:---|:---|
| S | >150% | 过强 | 削弱伤害15-30% |
| A | 120-150% | 偏强 | 微调伤害10-15% |
| B | 80-120% | 正常 | 无需调整 |
| C | 50-80% | 偏弱 | 微调增强10-20% |
| D | <50% | 过弱 | 增强伤害30-50% |

---

## 平衡性指标

### 计算方法

```javascript
// 平衡分数 (0-100)
score = 100
- 超标武器惩罚
- 不足武器惩罚  
- 高变异惩罚

// 合格标准
score > 70: 平衡良好
score 50-70: 需要微调
score < 50: 严重不平衡
```

### 阈值

| 指标 | 阈值 | 说明 |
|:---|:---:|:---|
| DPS变异系数 | 0.3 | >0.3认为不稳定 |
| 最低/最高比 | 0.5 | <0.5认为差距过大 |
| 超标阈值 | 1.5 | >1.5倍平均认为过强 |
| 不足阈值 | 0.7 | <0.7倍平均认为过弱 |

## 报告解读

### HTML报告包含

1. **总览** - 平衡分数、平均DPS、DPS范围
2. **分级表** - 所有武器按S/A/B/C/D分类
3. **详细数据** - 每个武器的测试统计
4. **调整建议** - 具体的伤害/CD调整建议

### 示例报告

```
平衡分数: 72/100 ✅

S级 (1个): 
  - 辉耀 DPS: 156 (155%)
  → 建议: 伤害降低 15%

B级 (12个):
  - 鞭子 DPS: 98 (98%)
  - 魔杖 DPS: 105 (104%)
  ...

C级 (1个):
  - 毒镔 DPS: 65 (64%)
  → 建议: 伤害增加 25%
```
