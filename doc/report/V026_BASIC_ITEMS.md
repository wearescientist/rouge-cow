## 二、系统特性

### 数值梯度设计
- **乘法类**（伤害、射速、移速）：逐级叠加，4个传说级约 ×2.5 总增益
- **加法类**（暴击、穿透、子弹）：线性递增
- **生命/护甲**：阶梯式，考虑游戏平衡

### 层数解锁机制
```javascript
unlockFloor: 1  // 1-2层掉落
unlockFloor: 3  // 3-4层掉落
unlockFloor: 5  // 5-6层掉落
bossDrop: true  // Boss必掉，无视层数
```

### 代码实现位置

1. **ITEMS定义** (line ~3278): 30个新道具定义
2. **getStats初始化** (line ~4583): 8个新属性初始化
3. **switch case处理** (line ~4778): 8个新效果分支
4. **效果计算** (line ~4938): 属性应用逻辑
5. **掉落过滤** (line ~19426): `getAvailableItemsByFloor()`
6. **商店过滤** (line ~14988): 商店使用层数过滤
7. **宝箱过滤** (line ~8400): 宝箱房使用层数过滤

## 三、6层数值平衡

**假设玩家一局获得12个道具**：
- 普通4个 + 稀有4个 + 史诗3个 + 传说1个

**纯攻击Build示例**：
- 1.12⁴ × 1.25⁴ × 1.40³ × 1.60 = **×8.5** 最终伤害

**混合Build示例**（攻击+射速+暴击）：
- 伤害：×3.9
- 射速：×2.8
- DPS：3.9 × 2.8 = **×10.9**

在合理范围内，终局强度适中。
