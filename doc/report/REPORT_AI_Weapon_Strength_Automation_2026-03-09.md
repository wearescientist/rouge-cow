- 新增 `scripts/ai-weapon-strength-test.js`，用于自动评估当前版本武器强度
- 测试脚本直接读取 `WeaponAndPassiveManager.js` 与 `weaponUpgrade.js`，不再依赖旧版 `index.html` 正则提取
- 自动覆盖三段阶段：
  - `Lv1`
  - `Lv8`
  - `超武`

  - `群怪`
  - `精英`
  - `Boss`
- 新版报告补充多维度指标：
  - `群怪压制`
  - `Boss压制`

  - `超武增幅`
  - `波动系数`
- 新版建议改为 `buff-first`，默认优先给补强方案，不主动输出削弱建议
- 输出 `reports/ai-weapon-strength-latest.json` 和 `reports/ai-weapon-strength-latest.md`

## 使用方式

- 运行 `npm run test:weapon:ai`
- 可选参数：
  - `node scripts/ai-weapon-strength-test.js --runs 120 --duration 60`

## 设计意图

- 统一当前武器数据源，避免旧测试脚本继续对过时表结构做分析
- 将武器成长阶段拆开看，避免只看基础武器或只看超武导致误判
- 让后续调表先有稳定基线，再做手感迭代

## 已知边界

- 当前仍是启发式 AI 战斗评估，不是浏览器内逐帧真实回放
- 该脚本更适合做横向比较和回归监控，不直接等价于玩家实机体感

## 最新回归结果

- 在 `--runs 80 --duration 45` 下，武器分布的 `最低/最高比` 已从 `0.125` 提升到 `0.388`
- 第一轮补强显著抬升了 `闪电 / 辉耀 / 镰刀 / 火球`
- 第二轮继续抬升了 `飞刀 / 冰锥 / 圣水 / 圣经`
- 当前仍处于长尾的主要对象是：
  - `圣水`
  - `圣经`
- 当前最适合继续补强的方向是：
  - `圣水`: 继续补 Boss 向伤害和超武追踪压制
  - `圣经`: 继续补单次命中倍率和超武压场爆发

## 评估标准切换

- 从“平均强度导向”切换为“定位导向”
- 新增每把武器的定位画像，定义：
  - 主胜场
  - 允许存在的弱点
  - 必须守住的成长或超武强度
- 后续自动化建议优先修复“没守住自身定位”的武器，而不是单纯把所有武器往均值拉平

## 定位补强回归

- 在定位导向标准下，继续强化了 `镰刀 / 火球 / 圣水 / 圣经` 的主胜场
- 本轮回归参数：`--runs 120 --duration 50`
- 最新结果：
  - `最低/最高比` 提升到 `0.451`
  - `圣水` 从 `D` 提升到 `C`
  - `圣经` 从 `D` 提升到 `C`
  - `镰刀` 进入更稳定的 `B` 区间
  - `火球` 进入更稳定的 `B` 区间

## 第二轮定向压场补强

- 继续只强化 `圣水 / 圣经` 的压场覆盖、持续时间、数量和频率
- 不主动补它们的 Boss 点杀短板，保持定位差异

  - `圣经` 综合分提升到 `2283.4`

## 手短问题修正

- 针对实机反馈，集中修复“短手武器难操控、视觉范围和实际命中不一致”的问题
- 主要处理：
  - `闪电` 首跳锁敌范围改为优先使用更大的起手范围，不再只吃过短的 `chainRange`
  - `辉耀` 实际生效半径扩大，并向视觉外圈对齐
  - `近战` 与 `闪电` 的基础攻击范围显著拉长
  - `圣经 / 圣水 / 斧头 / 火球` 等短手武器同步扩大可操作范围
- 为避免范围放大后纯数值过强，对部分武器同步做了轻量伤害回收
