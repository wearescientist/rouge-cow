# REPORT_Layer1_FullScene_Integration_2026-03-09

## 一、本轮目标

- 将第一层 `灰白菌丝完整镜头样板` 接入正式游戏视觉链路
- 不改核心玩法边界，先让三栏布局读成同一个灰白洞穴世界
- 继续维持 `HUD 在后处理上层` 的既有规则

## 二、本轮改动

- 在 `index.html` 中为第一层主题新增完整镜头相关变量，并把 `mycelium` 的 HUD 主色从偏灰绿收回灰白、骨白、灰褐
- 调整 `#mainLayout`、`#leftSidebar`、`#rightSidebar`、`#centerGame` 的背景层，让 HUD 两侧先具备同世界观的侧景与缓冲带
- 在 `src/systems/Room.js` 中为第一层房间新增 `drawLayer1FullSceneEnvelope()`，补入上远景、左右压暗、下前景与孢子空气
- 同步更新 `src/systems/rooms/Room.js`，避免房间模块双份实现继续漂移

## 二点五、结构调整

- 根据后续要求，将“第一层完整镜头壳层样式”从 `index.html` 内联样式中抽离到独立文件 `src/styles/floor-scene-shell.css`
- `index.html` 仅保留样式引用，不再继续承载这一轮新增的完整镜头 CSS 细节
- 后续若继续扩展其他楼层的完整镜头壳层，优先在独立样式文件中演进，而不是回写到 `index` 内联块

## 三、风险控制

- 没有改相机尺寸，避免误伤当前 `1:1` 核心玩法视野与碰撞判定
- 第一层外围景别仅使用环境渐变和粒子，不遮挡角色、敌人和掉落物读图
- HUD 侧区新增的是低频世界底景，不把高对比材质直接压到信息层后方

## 四、未完成项

- 中央战斗画布仍然是正方形，不是最终意义上的完整 `16:9` 玩法镜头
- 第一层外围景别目前是程序化氛围层，不是正式绘制资产
- 其他楼层尚未建立对应的完整镜头语法

## 五、验证结论

- 结构上已完成“中央方形玩法区 + 两侧世界侧景 + HUD 上浮”的第一阶段接入
- 第一层主题已从偏灰绿收回更接近设计稿要求的灰白洞穴观感
- 下一步应继续把正式素材接进四周景别，并评估是否进入中央画布比例调整阶段
