# REPORT_HUD_Mobile_Refresh_v0.33

## 日期
2026-03-08

## 本轮目标
- 以战斗内 HUD 作为整体 UI 锚点
- 统一桌面 HUD 的视觉语法
- 为移动端补独立顶部 HUD 与上下文交互按钮

## 完成内容
- 将桌面左右侧 HUD 从冷色玻璃卡片改为更偏洞穴手工记录板的暖暗色风格
- 重做状态条、武器列、被动列、道具格、小地图与顶部状态条的颜色层级
- 新增移动端顶部 HUD：左上生命/经验，右上透明小地图
- 新增移动端掌机式操作区：摇杆 + 对话 + 上下文交互 + 暂停 + 冲刺
- 为移动端补充上下文交互判断，支持宝箱开启/关闭、商店进出、NPC 对话续行
- 为移动端补充 1/2/3 选择条，覆盖商店购买与宝箱三选一操作
- 小地图改为同时绘制桌面与移动端画布

## 风险控制
- 未改动房间生成、战斗结算、物品掉落等核心玩法逻辑
- 上下文交互优先复用既有 `openShop()/closeShop()/openChestSelect()/selectChestItem()` 链路
- 移动端未新增独立存档或输入协议，仍沿用现有键位与 UI 行为

## 待验证项
- 实机触屏下，宝箱与商店卡片点击是否与底部选择条配合顺畅
- 移动端右侧按钮在极窄屏下是否会遮挡战斗画面关键区域
- 桌面 HUD 的暖色化是否与当前地图与敌人贴图产生冲突
