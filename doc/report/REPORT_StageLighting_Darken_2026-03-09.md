# REPORT_StageLighting_Darken_2026-03-09

## 本次调整

- 为 `RoomBlurSystem` 增加外围压暗与冷色调过渡，让失焦区同时进入暗部
- 收紧 `HD2DRenderer.renderPlayerVignette()` 的中心亮斑，并增强房间舞台暗角
- 降低 `SimpleLighting` 的环境底亮度，避免黑位被整体抬高

## 目标

- 让画面从“只有模糊”升级成“模糊 + 暗部收光”
- 提升房间边缘沉浸感，强化中心主体的镜头聚焦
- 继续向八方旅人式的舞台化亮度关系靠拢

## 风险控制

- 没有修改主角、敌人、商店紫域的绘制顺序
- 没有动移轴焦点跟随逻辑
- 只调整后处理和环境亮度，不改交互与碰撞链路

## 亮区收缩

- 收窄玩家动态光范围与强度，避免房间中区被整体托亮
- 缩小中心亮斑与清晰区半径，同时保留较宽的过渡区
- 让外围压暗更早介入，把亮区明显往里收

## 旧暗角试验

- 将 `renderPlayerVignette()` 的暗角内外半径直接缩为当前值的一半
- 本次只验证旧暗角透明区是否是中区过大的主因，不涉及动态光范围调整
- 试验后确认方向正确，再把暗角半径回拉到中间值，缓解“核心区过小、过渡变硬”的问题
- 在保持当前范围的前提下，重新分布渐变停点，软化透明区到暗场的过渡
