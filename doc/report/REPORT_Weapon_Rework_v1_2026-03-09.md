# REPORT_Weapon_Rework_v1_2026-03-09

## 本轮完成

- 将 `whip` 的对外语义替换为“圣剑”，保留内部 key，降低旧调用链和存档风险
- 重排武器进化配方，建立严格 `1:1` 的武器-被动对应关系
- 新增 `focus_lens`、`alchemist_flask` 两个被动，补齐 15 把武器的唯一进化入口
- 将激光升级轴从“加数量”改为“加粗度 + 加持续时间 + 提高持续命中频率”
- 将超武激光 `prism_beam` 改为沿移动方向喷射、仅在限定扇区内曲线索敌的贯穿束
- 将旧鞭子近战视觉替换为圣剑弧斩表现

## 同步修正

- 修正被动 `lifeSteal` 未进入战斗属性的问题
- 修正 `range / projSpeed / duration` 被动统计未进入运行时 `stats` 的问题
- 为超武闪电 `storm_arc` 增加随机落雷行为
- 为新超武闪电补充音效映射
- 修正暴击此前只影响飘字和特效、不稳定影响实际伤害的问题
- 将武器专属词条统一下沉到攻击体，补齐 `crit / critDmg / execute / freeze / blind / plagueBurst / divineNova / returnDamage / returnToPlayer`
- 为敌人补充 `blindTimer`，并统一冻结/眩晕/减速的运行时反馈
- 让圣水和超武圣水正确按数量生成多片区域，并为 `la_borra` 补上追踪水池移动逻辑
- 让闪电 `fork / branches`、火球 `secondaryExplosion`、毒镖 `burstOnDeath`、圣经 `eternal` 等升级表字段真正进入实战
- 修正激光升级表仍沿用旧“加数量”语义的问题，统一改为粗度/持续/命中频率成长

## Shadow Review

- 避免了直接改 `whip` key 导致的武器池、进化表、旧逻辑失配
- 避免了只改 `Weapon.fireLaser()` 而未改碰撞/渲染，导致“看起来追踪，实际仍按直线判定”的错位
- 避免了新 1:1 被动名义生效、实际未进入 `stats` 的空接线问题
- 避免了升级表字段持续堆积但运行链路不消费，导致后续调表继续建立在假机制上

## 已知边界

- 本轮主要重做了圣剑语义、激光成长和部分武器差异化描述，尚未把所有超武的特殊词条全部落成完整独立机制
- 现有工作区存在大量用户已有改动，本轮未做清理或回滚
- 未做完整实机回归，当前验证仍以静态检查和战斗链局部抽查为主
