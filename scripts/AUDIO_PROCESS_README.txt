🎵 音效处理指南
═══════════════════════════════════════════════════════════

需要完成两件事：
1. 火球音效缩短到1.5秒
2. 统一所有音效音量

═══════════════════════════════════════════════════════════
方法1：使用 Python 脚本（推荐）
═══════════════════════════════════════════════════════════

【步骤1】安装依赖

打开命令行，运行：
    pip install pydub

下载 FFmpeg：
    https://ffmpeg.org/download.html#build-windows

解压后将 bin 文件夹添加到系统环境变量 PATH

【步骤2】运行脚本

    cd E:\AI\game\rougelike-cow\scripts
    python audio_processor.py

脚本会自动：
✅ 截取火球音效前1.5秒
✅ 将所有音效音量标准化到 -14dBFS
✅ 备份原文件为 .backup

═══════════════════════════════════════════════════════════
方法2：使用音频编辑软件（手动）
═══════════════════════════════════════════════════════════

【推荐软件】

1. Audacity（免费）
   下载: https://www.audacityteam.org/
   
   火球音效处理：
   - 打开 fireball_v1.mp3
   - 选择前1.5秒（1500ms）
   - 效果 → 淡出（100ms）
   - 文件 → 导出 → MP3
   - 覆盖原文件
   
   音量平衡：
   - 打开每个音效文件
   - 效果 → 标准化
   - 设置峰值 -1dB
   - 导出覆盖

2. Adobe Audition（专业）
   - 批量处理更方便

═══════════════════════════════════════════════════════════
方法3：在线工具（最简单）
═══════════════════════════════════════════════════════════

【火球音效截取】
https://mp3cut.net/cn/

1. 上传 fireball_v1.mp3
2. 选择前1.5秒
3. 导出并覆盖原文件

【音量标准化】
https://www.mp3louder.com/
或
https://www.freeconvert.com/normalize-mp3

注意：在线工具可能不支持批量处理

═══════════════════════════════════════════════════════════
检查清单
═══════════════════════════════════════════════════════════

处理完成后，检查：

□ 火球音效时长 ≈ 1.5秒
□ 所有音效音量听起来差不多大
□ 没有爆音或削波失真
□ 游戏内音量调节正常工作

═══════════════════════════════════════════════════════════
回滚操作
═══════════════════════════════════════════════════════════

如果处理不满意，恢复备份：

删除处理后的文件，将 .backup 文件重命名：
    del fireball_v1.mp3
    ren fireball_v1.mp3.backup fireball_v1.mp3

或者使用脚本恢复（如果有）：
    python restore_backup.py
