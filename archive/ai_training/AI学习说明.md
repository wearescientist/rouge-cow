# 🧠 AI 学习过程说明

## 为什么AI一开始表现很差？

### 1. 初始状态（前10局）
- **Q值表为空** - AI没有任何经验
- **纯随机探索** - 30%概率完全随机行为
- **策略权重默认** - 没有优化过的默认权重

### 2. 典型表现
- ❌ 在第一个房间疯狂抖动找不到门
- ❌ 追着敌人打却不进下个房间
- ❌ 原地转圈圈浪费时间
- ❌ 不会逃跑，死了也不跑

### 3. 这是正常的！

就像人类学习游戏一样，AI也需要：
- **探索阶段** - 尝试各种行为
- **失败积累** - 从死亡中学习
- **策略优化** - 调整行为权重

## 什么时候会看到改善？

| 训练局数 | 预期表现 |
|---------|---------|
| 1-5局 | 完全随机，经常卡住 |
| 6-15局 | 开始学会基础行为（逃跑、探索） |
| 16-30局 | 明显进步，能通关低层数 |
| 30+局 | 策略成型，分数稳定增长 |

## 如何加速学习？

### 方法1：增加训练局数
建议至少训练 **20-50局** 才能看到效果

```bash
# 连续训练50局
node continuous_training.js --rounds=50 --speed=5
```

### 方法2：调整初始策略权重

修改 `ai_learner.js` 第32-37行：

```javascript
// 原默认权重
this.strategyWeights = this.learningData.strategyWeights || {
  SURVIVAL: 0.25,    // 生存
  COMBAT: 0.30,      // 战斗
  EXPLORATION: 0.30, // 探索 ← 提高这个
  COLLECTION: 0.15   // 收集
};

// 改为更偏向探索
this.strategyWeights = this.learningData.strategyWeights || {
  SURVIVAL: 0.20,
  COMBAT: 0.20,
  EXPLORATION: 0.50, // 提高到50%，让AI更爱探索
  COLLECTION: 0.10
};
```

### 方法3：降低探索率

修改 `ai_learner.js` 第23行：

```javascript
// 原值 0.3（30%随机探索）
this.epsilon = 0.3;

// 改为 0.2（20%随机探索），让AI更快利用学到的策略
this.epsilon = 0.2;
```

## 常见问题

### Q: AI一直死在同一种情况下？
A: 正常，它正在学习"这种情况会死"，后面就会避开

### Q: 分数不升反降？
A: 可能是探索期，让它继续训练，第10局后再看趋势

### Q: 怎么判断AI真的在学习？
A: 看 `ai_learning_data.json` 文件，如果 `gamesPlayed` 在增加，Q值表在变大，就是在学习

## 建议的训练计划
