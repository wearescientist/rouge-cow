# 牛牛肉鸽 AI 训练系统 v4.1 (v0.16.0 武器升级学习版)

🧠 **让AI自动玩游戏并自我进化！**

## 🚀 快速开始

### 1. 启动游戏服务器

确保游戏服务器在运行：
```
http://localhost:8080/
```

### 2. 启动AI训练

双击 `START.bat`，选择训练模式：

- **[1] 单次训练** - 单局游戏，适合测试
- **[2] 连续训练** - 多局连续，自动学习进化
- **[3] 观察模式** - 慢速观察AI行为
- **[4] 查看学习进度** - 查看AI成长数据

## 🧠 AI 学习系统

### 核心功能

- **Q-Learning 算法** - 记录状态-动作-奖励，建立Q值表
- **自适应策略权重** - 根据历史表现动态调整策略
- **探索vs利用平衡** - ε-贪婪策略平衡探索与利用
- **武器升级学习** (v0.16.0) - 智能选择武器升级，学习最优配置

### 策略类型

| 策略 | 权重 | 说明 |
|------|------|------|
| SURVIVAL | 20-25% | 生存优先（HP低时逃跑） |
| COMBAT | 30-45% | 战斗优先（击杀得分） |
| EXPLORATION | 22-30% | 探索优先（新房间得分） |
| COLLECTION | 14-15% | 收集优先（道具金币） |
| DOOR_SEEKING | 25-35% | 寻门优先（房间清理后找门） |
| RETURN | 5-10% | 返回策略（防止卡死） |

### 武器升级智能选择 (v0.16.0)

AI现在会智能选择武器升级：

- **优先升级已有武器** 到关键等级（4级和8级质变）
- **超武合成检测** - 当满足超武合成条件时，优先选择对应被动道具
- **武器类型优先级** - 根据武器强度动态调整选择权重
- **学习最优配置** - 记录不同武器组合的胜率，优化选择策略

#### 升级评分系统

| 等级 | 评分加成 | 说明 |
|------|----------|------|
| Lv4 | +100 | 质变等级（双鞭/分裂等） |
| Lv8 | +150 | 满级质变（三鞭/无限穿透等） |
| Lv1-3 | +30 | 早期升级 |
| Lv5-7 | +50 | 中后期升级 |
| 超武合成 | +200 | 满足合成条件时优先 |

## 🎮 训练模式

### 连续训练（推荐）

```
训练局数: 10-50局
游戏速度: 5x-10x
每局时间: 300秒
```

AI会在每局结束后：
1. 记录分数和决策
2. 更新Q值表
3. 调整策略权重
4. **记录武器配置效果** (v0.16.0)
5. 自动重新开始游戏

### 观察模式

```
训练局数: 3-5局
游戏速度: 1x
每局时间: 600秒
```

适合观察AI行为，检查学习效果。

## 📈 学习效果

随着训练进行，你会看到：

- **平均分数上升** - AI越来越擅长获得高分
- **策略权重优化** - 最有效的策略权重增加
- **探索率下降** - 从探索转向利用已知策略
- **武器胜率统计** (v0.16.0) - 显示各武器/等级的胜率
- **升级偏好学习** (v0.16.0) - AI学会优先选择高价值升级

## 🐛 故障排除

### 游戏加载失败
- 检查 http://localhost:8080/ 是否可访问
- 确保游戏服务器已启动

### 训练中断
- 重新运行脚本即可继续
- 学习数据会自动保存

### AI不学习
- 检查 `data/ai_learning_data.json` 是否存在
- 查看是否有决策记录
